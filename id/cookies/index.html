Ini adalah terjemahan kebijakan cookie kami. Jika berbeda dengan versi bahasa Inggris, versi bahasa Inggris yang berlaku.

Singkatnya

  • Situs web ini tidak menggunakan cookie.
  • Tanpa analitik, pelacakan, atau iklan.
  • Jika kamu memilih bahasa, browser-mu mengingatnya di perangkatmu.

Cookie

monkeyvinerush.com tidak memasang cookie apa pun, dan kami tidak menggunakan alat analitik, iklan, atau pelacakan apa pun. Karena itu kamu tidak akan melihat banner cookie di sini.

Pilihan bahasamu

Saat kamu memilih bahasa, situs menyimpan pilihan itu di penyimpanan lokal browser-mu (dengan nama mvr-lang) agar lain kali terbuka dalam bahasamu. Pilihan itu tetap di perangkatmu dan tidak pernah dikirim ke kami. Pilihan itu hanya disimpan karena kamu memintanya, dan kamu bisa menghapusnya kapan saja dengan membersihkan data situs ini di browser-mu.

Font dan hosting

Situs ini di-hosting di GitHub Pages dan font-nya berasal dari Google Fonts. Seperti situs web lainnya, saat browser-mu memuat halaman dan font, layanan ini menerima informasi teknis seperti alamat IP dan jenis browser-mu. Mereka tidak memasang cookie untuk situs ini. Kamu bisa membaca cara mereka menangani data di pernyataan privasi GitHub dan kebijakan privasi Google.

Game

Aplikasi Monkey Vine Rush juga tidak menggunakan cookie atau pelacakan. Lihat kebijakan privasi kami untuk mengetahui apa yang disimpan game.
