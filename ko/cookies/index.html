쿠키 정책

Monkey Vine Rush

최종 업데이트: 2026년 10월 26일

이 문서는 쿠키 정책의 번역본입니다. 영어 버전과 다른 경우 영어 버전이 우선합니다.

간단히 말하면

  • 분석 쿠키는 동의한 경우에만 사용돼요.
  • 광고 쿠키는 없고, 다른 사이트에서 추적하지도 않아요.
  • 언어를 선택하면 브라우저가 기기에 그 선택을 기억해요.

쿠키

동의하면 사이트는 Google 애널리틱스로 방문 수를 세고 어떤 페이지가 인기 있는지 확인해요. 다음 쿠키가 설정돼요:

  • _ga: 방문자를 서로 구별해요(2년간 보관)
  • _ga_2M1YFDZQH2: 현재 방문을 기록해요(2년간 보관)

Google 애널리틱스는 보는 페이지, 기기와 브라우저 종류, 대략적인 위치(IP 주소로 추정하며 IP 주소는 저장되지 않아요) 등을 기록해요. 이를 당신을 식별하거나, 광고에 쓰거나, 다른 사이트에서 추적하는 데 사용하지 않아요. 거부하거나 선택하지 않으면 이 쿠키는 설정되지 않고 Google 애널리틱스도 불러오지 않아요.

내 선택

선택한 내용은 브라우저의 로컬 저장소(mvr-consent라는 이름)에 저장돼요. 여기서 또는 모든 페이지 하단의 쿠키 설정에서 언제든지 바꿀 수 있어요.

언어 선택

언어를 선택하면 다음에도 그 언어로 열리도록 사이트가 그 선택을 브라우저의 로컬 저장소(mvr-lang라는 이름)에 저장해요. 이 정보는 기기에만 남고 저희에게 전송되지 않아요. 직접 선택했을 때만 저장되며, 브라우저에서 이 사이트의 데이터를 지우면 언제든지 삭제할 수 있어요.

글꼴과 호스팅

이 사이트는 GitHub Pages에서 호스팅되고 글꼴은 Google Fonts에서 불러와요. 다른 웹사이트와 마찬가지로 브라우저가 페이지와 글꼴을 불러올 때 이 서비스들은 IP 주소와 브라우저 종류 같은 기술 정보를 받아요. 이 사이트를 위해 쿠키를 설정하지는 않아요. 데이터 처리 방식은 GitHub 개인정보 보호정책과 Google 개인정보처리방침에서 확인할 수 있어요.

게임

Monkey Vine Rush 앱은 쿠키를 사용하지 않아요. 게임이 저장하는 내용은 개인정보처리방침에서 확인하세요.
