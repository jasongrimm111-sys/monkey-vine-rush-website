Cookie-Richtlinie

Monkey Vine Rush

Zuletzt aktualisiert am 23. Oktober 2026

Dies ist eine Übersetzung unserer Cookie-Richtlinie. Weicht sie von der englischen Fassung ab, gilt die englische Fassung.

Kurz gesagt

  • Diese Website verwendet keine Cookies.
  • Keine Analyse, kein Tracking, keine Werbung.
  • Wenn du eine Sprache wählst, merkt sich dein Browser sie auf deinem Gerät.

Cookies

monkeyvinerush.com setzt keine Cookies, und wir verwenden keinerlei Analyse-, Werbe- oder Tracking-Tools. Deshalb gibt es hier auch kein Cookie-Banner.

Deine Sprachauswahl

Wenn du eine Sprache wählst, speichert die Website diese Wahl im lokalen Speicher deines Browsers (unter dem Namen mvr-lang), damit sie beim nächsten Mal in deiner Sprache öffnet. Sie bleibt auf deinem Gerät und wird nie an uns gesendet. Sie wird nur gespeichert, weil du es so wählst, und du kannst sie jederzeit entfernen, indem du die Daten dieser Website in deinem Browser löschst.

Schriften und Hosting

Die Website wird bei GitHub Pages gehostet, und ihre Schriften kommen von Google Fonts. Wie bei jeder Website erhalten diese Dienste beim Laden der Seiten und Schriften technische Angaben wie deine IP-Adresse und deinen Browsertyp. Sie setzen für diese Website keine Cookies. Wie sie mit Daten umgehen, erfährst du in der Datenschutzerklärung von GitHub und der Datenschutzerklärung von Google.

Das Spiel

Auch die App Monkey Vine Rush verwendet keine Cookies und kein Tracking. Was das Spiel speichert, steht in unserer Datenschutzerklärung.
