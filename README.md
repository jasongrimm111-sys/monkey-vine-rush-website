# monkeyvinerush.com

The homepage for **Monkey Vine Rush** by Grimmitt Games, served by GitHub Pages at https://monkeyvinerush.com.

- `index.html`: the whole page (no build step)
- `img/`: icon, screenshots, trailer and share image
- `CNAME`: the custom domain

Support and privacy pages live in the `monkey-vine-rush-privacy` repo.
